# ASIG: one design language, your framework

## Intent

1. Product: ASIG, a framework-neutral design token and CSS pattern library.
2. Demonstrable claim: the same Orders screen can be built in plain JavaScript, React/Next.js and Angular with the published 0.7.0 packages.
3. Hook: “One design language. Your framework.” Show the actual Orders starter in the first scene.
4. Actual UI: screenshots from the production JavaScript starter, captured by the repository's opt-in browser test. Fictional records only. The three frameworks have browser-tested equivalent behavior.
5. Length: 20 seconds, landscape 1920×1080. One idea, two state changes, one next step.
6. Tone: polished, calm, developer-facing. Operations blue palette and the repository's local Inter font.
7. Audio: intentionally silent for a muted documentation/social preview. All meaning is carried by readable captions; no narration, music or reactive decoration competing with code/UI reading.
8. Share caption: “One design language, your framework. Try ASIG's standalone JavaScript, Next.js and Angular starters: search, filter and switch themes while your application owns the behavior.” Add the quickstart link only after deployment.
9. User flow: understand the CSS/runtime boundary, see a real interaction result, choose a framework and run the starter.

## Composition brief

Use authentic screenshot states, not reconstructed controls or invented ERP metrics. Cursor cues illustrate the already-tested actions; the composition itself is a deterministic visual sequence, not a live app. Use one registered paused GSAP timeline. Adapt the registry's line-by-line-slide headline primitive; local assets only. Keep all product text legible. Preserve the final frame. No release or download claims. No implication of bundled framework components.

## Review and distribution

The preview is the review surface. Render only after final preview approval, per the brag/HyperFrames workflow. Do not publish the video or outreach copy automatically. The quickstart URL will only work publicly once these changes are deployed.
