## Short post

One design language, your framework. ASIG has runnable JavaScript, Next.js and Angular starters: search, filter and switch themes while your application owns the behavior. Open source, MIT licensed.

## Developer introduction

Getting started with a design system should include a working example.

ASIG's new starters show the same Orders screen in plain JavaScript, Next.js + React and Angular. Shared tokens and CSS provide the appearance; native events, React callbacks or Angular signals implement the behavior. Each starter includes its own lockfile, fictional data, four themes and an accessible filtering example.

Try one, build a small screen and tell us where the instructions fall short:
https://prabhuvajjiram.github.io/agis/site/start.html

Source and contributions: https://github.com/prabhuvajjiram/agis

## A useful first contribution

Help someone build their first ASIG screen. Run a starter in your preferred framework and report unclear setup steps, keyboard issues or a missing state example. Include a small reproduction with invented data. Documentation fixes and focused examples are welcome.

https://github.com/prabhuvajjiram/agis/issues/new/choose

## First adoption milestone

After publication, invite a small number of developers to run a starter and provide specific feedback. Track successful independent setups and useful issue/PR reports. Treat npm download counts as distribution activity, not a count of people or active applications. Revisit examples based on observed setup problems before expanding the framework list.
