# Catalogue font

The catalogue self-hosts the Latin variable-weight build of Inter so visual tests use the
same typography on macOS, local Linux containers, and GitHub Actions.

- Source package: `@fontsource-variable/inter@5.3.0`
- Source file: `files/inter-latin-wght-normal.woff2`
- SHA-256: `3100e775e8616cd2611beecfa23a4263d7037586789b43f035236a2e6fbd4c62`
- License: SIL Open Font License 1.1, reproduced in `INTER-OFL.txt`

Do not replace the font binary without updating the version, checksum, licence copy, and
all reviewed visual baselines.
